# 🎨 Figma to Website

<div align="center">

### Transforming Figma Designs into Fully Responsive Websites

A collection of **5 pixel-perfect frontend implementations** built by converting Figma UI designs into functional websites using **HTML, CSS, and JavaScript**.

---

## 🚀 About The Project

This repository showcases my ability to convert modern Figma designs into responsive and interactive web interfaces while maintaining design consistency, visual accuracy, and clean code structure.

Each project was developed by carefully analyzing the original design and recreating it using frontend technologies without relying on website builders or UI frameworks.

The focus was on:

- 🎯 Pixel-perfect implementation
- 📱 Responsive layouts
- ⚡ Clean and organized code
- 🎨 Modern UI design practices
- 💡 Frontend development fundamentals
